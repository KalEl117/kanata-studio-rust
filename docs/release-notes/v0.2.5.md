## Highlights

- **First start without a Kanata configuration:** instead of only reporting that the file could not be opened, the app now shows a first-start screen. It asks before creating a configuration and shows whether Kanata, `kanata.service`, and a keyboard were found (Kanata is needed to check, save, and test; the service to save and test).
- **Starter configuration:** `defsrc` lists every key of the detected keyboard with the usual short Kanata names (`esc`, `caps`, `lsft`, …), and the base layer keeps every key's normal function (`_`). If Kanata is installed, it checks the file before it is written. An existing file is never replaced. The file goes where `kanata.service` expects it, otherwise to `~/.config/kanata/kanata.kbd`.

## Fixes

- Without `~/.config/kanata/kanata.kbd` or `config.kbd`, the app now also opens the file `kanata.service` runs.
- `slck` and `menu` in `defsrc` are now shown on the drawn Scroll Lock and Menu keys (app and Omarchy plugin).

Kanata Studio does not install Kanata or set up `kanata.service`; the first-start screen only shows what is missing.

## Install

Download `install.py` from the assets below and run `python3 install.py`. It downloads this release, verifies the checksums, and installs the app (plus the plugin on Omarchy). Run it again to update an existing installation. Use `--app-only` to skip the plugin and `--check-only` to only verify the downloads.

Requirements: x86_64 Linux with glibc 2.36+, Python 3.10+, and a desktop graphics stack (Mesa or another GLVND driver). Built on Debian 12; smoke-tested on Debian 12, Ubuntu 24.04, and Fedora 44. Requires Kanata and a `kanata.service` user service to check, save, and test. See the README.
