First binary release since v0.2.0/v0.2.1 were withdrawn. The archives now include complete license files and corresponding source materials (see [LICENSING.md](LICENSING.md)). Do not use copies of the withdrawn archives.

## Highlights

- **`deflayermap` support:** configs that use `deflayermap` now open. Map layers appear in file order alongside `deflayer` layers and resolve keys like Kanata. They are read-only in the key editor; edit them as text under *Configuration*.
- **Device-aware layout detection:** the keyboard view follows the device filters of the open config and follows hot-plugging. USB keyboards are preferred, and known firmware keyboards (e.g. Adv360 Pro) are excluded. The app and the Omarchy plugin share one keyboard model.
- **No more freezes while checking or saving:** check, save, and the 30-second test now run in the background.

## Fixes

- Switching the UI language reset the tap-hold form to *Modifier / Left Ctrl*; applying it then replaced the real hold action with `lctl`. Selections now survive language and layer-list changes.
- `kanata.service` units using `--cfg` (or `-c=`/`--cfg=`) were not recognised, so saving and testing were refused.
- Files that are not valid UTF-8 are refused instead of being altered on save; a UTF-8 BOM is preserved.
- Renaming or deleting a layer now also covers layer names in `defchordsv2` and `defoverridesv2`.
- The status indicator shows errors in red reliably (some errors were shown in green).
- The recovery service path is escaped for systemd (paths containing `%` broke the unit).

## Install

Download `install.py` from the assets below and run `python3 install.py`. It downloads this release, verifies the checksums, and installs the app (plus the plugin on Omarchy). Use `--app-only` to skip the plugin and `--check-only` to only verify the downloads.

Manual install: verify the app archive with `sha256sum -c`, extract it, and run the `install.py` inside.

Built on Debian 12 (glibc ≤ 2.36); smoke-tested on Debian 12, Ubuntu 24.04, and Fedora 44. Requires Kanata and a `kanata.service` user service. See the README.
