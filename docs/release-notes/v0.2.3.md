## Highlights

- **Edit `deflayermap` layers:** map layers are no longer read-only in the key editor of the app and the Omarchy plugin. Changing a key that already has a mapping replaces only its action; otherwise a `key action` entry is added to the map. The `_`/`___` fallback is never changed, because it also applies to other keys. Map layers can now also be used as a template for a new layer.
- **More consistent interface:** all dialogs share one themed title bar and spacing, the language and block selectors match the rest of the app, buttons have proper padding, and disabled buttons look disabled.

## Fixes

- On laptop layouts, the ← ↓ → row sat 5 px to the right of PageUp ↑ PageDown and overhung the keyboard edge (app and plugin).
- The configuration dialog showed literal backticks around `defsrc`/`deflayer`.
- `--ui-check` without a config now says so instead of reporting a misleading form failure.

## Release process

Release archives are now attached to a draft release by CI after the build and all container tests pass; publishing remains a manual step.

## Install

Download `install.py` from the assets below and run `python3 install.py`. It downloads this release, verifies the checksums, and installs the app (plus the plugin on Omarchy). Run it again to update an existing installation. Use `--app-only` to skip the plugin and `--check-only` to only verify the downloads.

Manual install: verify the app archive with `sha256sum -c`, extract it, and run the `install.py` inside.

Built on Debian 12 (glibc ≤ 2.36); smoke-tested on Debian 12, Ubuntu 24.04, and Fedora 44. Requires Kanata and a `kanata.service` user service. See the README.
