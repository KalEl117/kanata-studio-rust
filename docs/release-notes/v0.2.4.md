Fixes the app not starting on most current desktops in v0.2.2 and v0.2.3. The Omarchy plugin was not affected.

## Fixes

- **App failed to start on systems with a newer graphics stack than Debian 12** (e.g. Arch/Omarchy, current Fedora and Ubuntu): "EGL not available", "Failed to initialize graphics backend". The package shipped older copies of system libraries (libstdc++, Wayland, libdrm, EGL/GLVND, X11/xcb, zlib/zstd/expat/ffi) that prevented the system Mesa driver from loading. These libraries now come from the system, like glibc. Qt itself is still bundled.
- **Updating left files from the previous installation behind.** The installer now replaces the installation directory instead of copying over it, so plugins or libraries from an older or locally built version can no longer break the new one.

## Testing

The container tests now install the distribution's Mesa driver and check that it loads next to the bundled libraries (`tools/check-host-graphics.py`). On an affected system (Omarchy) it fails for the v0.2.3 package.

## Install

Download `install.py` from the assets below and run `python3 install.py`. It downloads this release, verifies the checksums, and installs the app (plus the plugin on Omarchy). Run it again to update an existing installation. Use `--app-only` to skip the plugin and `--check-only` to only verify the downloads.

Requirements: x86_64 Linux with glibc 2.36+, Python 3.10+, and a desktop graphics stack (Mesa or another GLVND driver). Built on Debian 12; smoke-tested on Debian 12, Ubuntu 24.04, and Fedora 44. Requires Kanata and a `kanata.service` user service. See the README.
